# Ace Club — Learning Log

## Purpose

This document records meaningful changes in engineering understanding.

The fresh implementation is an opportunity to compare new reasoning with patterns from the previous attempt, but only after independent reasoning has occurred.

Record:

- incorrect mental models;
- surprising mechanisms;
- recurring mistakes;
- meaningful changes in architectural judgment;
- cases where the new implementation differs from the previous one for a reason you can now explain.
