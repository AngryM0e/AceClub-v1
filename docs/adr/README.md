# Architecture Decision Records

This directory contains ADRs for the fresh Ace Club implementation.

ADRs describe decisions made for the **current** codebase.

Do not create an ADR merely to preserve a decision from the previous attempt.

If an old and new decision are the same, the new ADR should still explain the current reasoning independently.

```text

0002-example-decision.md
```
